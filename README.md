# Shayari Reel Maker

Shayari paste karo, 9:16 reel video banao, Instagram par upload karo.
Features: pure black theme, font size, page naam (position + color), background image, music.
Sab kuch browser me chalta hai. Koi server, app ya install nahi chahiye.

## Setup (ek baar, phone ya laptop se)

### 1. GitHub account
github.com par free account banao (agar nahi hai).

### 2. Naya repo
1. Chrome me github.com kholo, login karo.
2. **+** > **New repository**.
3. Name: `shayari-reel-maker`
4. **Public** chuno (free Pages ke liye zaroori).
5. **Create repository**.

### 3. Files upload karo
1. Zip ko phone ke Files app me extract karo (long press > Extract / Uncompress).
2. Repo page par **Add file > Upload files**.
3. `index.html` aur `README.md` chuno.
4. **Commit changes**.

Zip extract nahi kar sakte? **Add file > Create new file**, naam `index.html`, code paste karo, Commit.

### 4. GitHub Pages on karo
1. Repo me **Settings** > **Pages**.
   (Phone par Settings na dikhe to Chrome menu me **Desktop site** on karo.)
2. Source: **Deploy from a branch**.
3. Branch: **main**, folder: **/ (root)**, **Save**.
4. 1-2 minute ruko. Link aayega:
   `https://<tumhara-username>.github.io/shayari-reel-maker/`

### 5. Phone ki home screen par rakho
Chrome me link kholo > menu (3 dot) > **Add to Home screen**. Ab app jaisa khulega.

## Roz ka use
1. Link kholo, shayari paste karo.
2. Theme, font size, naam, background image set karo.
3. **Preview dekho**, phir **Video banao**.
4. Video bante waqt app/tab khula rakho aur screen lock mat karo.
5. **Instagram par share karo** dabao, share menu me Instagram chuno, phir **Reels** (ya Story) chuno. Video seedha Instagram editor me khulega.
   Share menu na khule to **Video download karo** dabao aur Instagram me + > Reel se upload karo.

## Update kaise karein
Naya `index.html` mile to repo me **Add file > Upload files**, same naam se upload karo, Commit.
1-2 minute me site update ho jayegi.

## Dikkat aaye to
- **404 page**: 2-3 minute ruko. Settings > Pages me branch `main` aur `/ (root)` check karo. File ka naam exactly `index.html` ho.
- **Purana version dikh raha hai**: page refresh karo ya browser cache clear karo.
- **Hindi font nahi dikha**: internet chalu rakho (Google Fonts load hote hain).
- **Download `.webm` aaya**: Instagram ko mp4 chahiye. Android/laptop Chrome me banao ya free converter se mp4 kar lo.
- **Video beech me ruk gaya**: screen on rakho aur dusre app/tab me mat jao.
